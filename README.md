# BLANP

Official implementation of:

**BLANP: Memory-Efficient Backpropagation-Free Local Training via Antithetic Node Perturbation**

Accepted at the **40th Conference on Neural Information Processing Systems (NeurIPS 2026)**.

## Overview

This repository contains the official implementation of **BLANP**, a backpropagation-free local learning method based on **Antithetic Node Perturbation**.

## Code

The source code and instructions for reproducing the experiments will be provided in this repository.
